# Student Stress Prediction System

A Machine Learning based web application that predicts student stress levels based on academic, personal, and lifestyle factors.

## Features

* Predicts stress level using Machine Learning
* User-friendly web interface
* Flask REST API backend
* Deployed on Render

## Technologies Used

* Python
* Flask
* Scikit-learn
* Random Forest Classifier
* GitHub
* Render
* Lovable AI

## Input Features

* Study Hours
* Sleep Hours
* Attendance Percentage
* CGPA
* Social Media Hours
* Physical Activity Hours
* Family Pressure
* Financial Stress
* Exam Score

## Output

* Low Stress
* Medium Stress
* High Stress
